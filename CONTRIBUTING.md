# Contributing

Thanks for contributing to ToolStack Backend.

## Before submitting a change

- Keep changes focused and easy to review.
- Do not commit secrets, credentials, environment files, or generated artifacts.
- Verify the project still runs with the repository's current dependency setup.
- Update documentation when behavior or setup changes.

## Pull requests

Include a concise description of the change, relevant testing performed, and any known limitations.
